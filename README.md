# FIFA World Cup 2026 - Player Performance Analysis

A data science project analyzing FIFA World Cup 2026 player 
performance data using Python, Pandas, Matplotlib, and 
Scikit-learn.

## Project Overview
This project performs a full end-to-end data analysis on a 
dataset of 54,600 player performance records across 75 features, 
including goals, assists, passing accuracy, ratings, and 
physical metrics.

## Analysis Performed
- Top 10 goal scorers of the tournament
- Top 10 nationalities represented
- Average player rating by position (Forward, Midfielder, 
  Defender, Goalkeeper)
- Machine learning model to predict player ratings

## Visualizations
- Bar chart — Top 10 goal scorers
- Bar chart — Top 10 nationalities
- Bar chart — Average rating by position

## Machine Learning Model
- Algorithm: Linear Regression (scikit-learn)
- Target: Player rating prediction
- Features used: goals, assists, pass accuracy, 
  shots on target, distance covered
- Model Score: 69% accuracy
- Mean Squared Error: 3.04

## Technologies Used
- Python
- Pandas — data loading and analysis
- NumPy — numerical operations
- Matplotlib — data visualization
- Scikit-learn — machine learning model

## Dataset
FIFA World Cup 2026 Player Performance Dataset
Source: Kaggle

## How to Run
python3 fifa_analysis.py

## Key Findings
- Memphis Zerrouki was the top scorer with 24 goals
- Qatari players had the highest representation
- Forwards had the highest average rating among all positions
- Goalkeepers rated significantly lower than outfield players
